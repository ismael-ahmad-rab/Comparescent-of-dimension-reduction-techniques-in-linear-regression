# Comparescent-of-dimension-reduction-techniques-in-linear-regression
In the era of big data techniques to reduce the dimensionality of input are of great use. However, in the context of supervised learning, such techniques don't take into consideration the target variable.
We consider the following 3 regression techniques based on PCA, comparing them in a simulation study: 
- Principal Component Regression
- Partial Least Squares Regression
- Sparse Principal Component Regression

The study places more emphasis on the last of these methods: Sparse Principal Component Regression.

This study is motivated as the project for the subject, "Advanced Regression and Prediction", as part of the Master "in Statistics for Data Science" offered by UC3M (Madrid 2023-2024)
